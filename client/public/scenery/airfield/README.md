# Airfield scenery atlases

These materials were generated for this project and are bundled for offline use.

- `foliage.webp` contains four alpha-masked clusters of twig sprays at 1024 × 1024. The top two rows of 496 pixels hold the leaf cards. The strip at the bottom supplies bark texture tinted by vertex colors. The renderer places the sprays on four branching meshes.
- `hangar.webp` is a 1024 × 1024 atlas with the door facade, windowed side, standing-seam roof and plain metal cladding in reading order. The walls and pitched roof share one material.
- `turf.webp` is a 1024 × 1024 seamless grass detail tile. The renderer blends it with the Poly Haven grass photograph in field coordinates.
