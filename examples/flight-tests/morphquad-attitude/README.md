# MorphQuad 完整四模式测试模板

默认内置模板为 **完整四模式 · 矢量速率 / 回中保持 / 一键回平**。在“PX4 工具箱 → 仿真测试 → 模板”中载入。完整模板和四个分组均会手动起飞至所选高度（默认 10 m），结束或异常时降落并确认着陆上锁。载入模板不会启动测试。

## 文件

| 文件 | 内容 |
| --- | --- |
| `10_four_mode_complete.xml` | 手动 → 定高 → 普通定点 → 矢量定点，四组均含 Pitch、Roll、航向 |
| `11_four_manual.xml` | 手动三轴，Pitch/Roll ±35°，每点回位零速 |
| `12_four_altctl.xml` | 定高三轴，Pitch/Roll ±20°，每点回位零速 |
| `13_four_posctl.xml` | 普通定点双轴 ±60%打杆刹停、航向 ±90° |
| `14_four_vector.xml` | 矢量定点双轴速率、回中保持、一键回平及航向 ±90° |

每个文件可回导为积木。`07_vector_pitch.xml`、`08_vector_roll.xml` 和 `09_posctl_regression.xml` 也使用速率输入。旧固件九阶段保留 AUX 角度测试。新完整模板是当前界面默认选项，更新后的 MCP 内置完整脚本也指向该模板。

## 测试序列

| 测试组 | Pitch / Roll | 每点保持 | 航向 |
| --- | --- | --- | --- |
| MANUAL | ±35°，5°步进 | 2 s，随后回位 | 相对起飞基准 ±90°，30°步进，保持 2 s 后回位 |
| ALTCTL | ±20°，5°步进 | 2 s，随后回位 | 同上，整个测试与回位均保持 ALTCTL |
| 普通 POSCTL | 每轴 +60%、−60%，各 2 s | 检查倾角 ≥1°、地速 ≥0.3 m/s，随后刹停 | 相对基准 ±90°，30°步进，保持 10 s，同时检查定点 |
| 矢量 POSCTL | 两轴分别打 ±35% 速率杆，达到 ±3° 后回中 | 检查低角速度与非零姿态，短按回平后检查两轴 ≤1.5° | 相对基准 ±90°，30°步进，保持 10 s，同时检查定点 |

手动和定高按正负角度扫描，完整模板包含 92 个姿态角点、52 个航向点、4 次普通定点打杆和 4 个矢量速率动作。矢量组先在开关关闭时进入普通定点并稳定，再打开矢量开关。航向经主偏航杆控制，横滚与俯仰速率使用专用 RC 通道。

起飞稳定后统一记录一次固定水平原点与基准航向。手动和定高每一个姿态点、航向点结束后均返回该固定原点；物理姿态回平后，计划目标角度仍按序列继续累计。航向点回位期间保持该点目标航向，每组最后回到起飞基准航向。定高回位不切换 Position。

## 一个参数化“回位”积木

所有恢复和定点刹停共用一个“回位”积木，内部保留 `manual_recover` 标识以兼容已有脚本。参数包括：

- 动作：记录原点并稳定、返回固定原点、仅刹停并稳定。
- 适用模式：保持当前模式，或校验 MANUAL / ALTCTL / POSCTL。模块不会自动切换飞行模式；运行期间模式改变会终止测试。
- 航向：保持当前测试目标，或回到基准航向。
- 位置/速度容差、连续稳定时间、返程速度、倾角、加速度、倾角变化速度及超时。

“返回固定原点”用于 MANUAL / ALTCTL：通过主 Roll/Pitch 杆先制动，再低速返回；MANUAL 按倾角换算，ALTCTL 按其加速度映射换算。普通/矢量 POSCTL 选择“仅刹停并稳定”，主杆回中，由 PX4 的位置环制动。

默认完成条件为：水平位置误差 ≤0.5 m（固定原点返回）、水平速度 ≤0.2 m/s、总倾角 ≤3°、总角速度 ≤3°/s、高度误差 ≤0.5 m、升降速度 ≤0.3 m/s。带航向目标时还要求航向误差 ≤3°。所有条件连续满足 2 s 才完成；偏离任一项均重新计时。仅刹停动作不要求返回起飞原点。

回位须与油门控高并行。新模板的单点回位超时为 120 s，普通/矢量定点刹停为 30 s；失败后结束后续点并执行退出策略。

## 航向与参数预检查

航向积木使用相对统一基准的目标角，处理跨越 ±180°/0°/360°的环绕误差。默认目标变化上限 10°/s，结合 `MPC_MAN_Y_MAX`、`MAN_DEADZONE`、`VEC_HEAD_RATE` 进行杆量换算和限速；到位稳定 2 s 后再累计保持时间。偏离会重新计时。定点航向还要求水平误差 ≤1 m、水平速度 ≤0.2 m/s。

新版模板使用完整 RC 帧和 `COM_RC_IN_MODE=0`。运行前按飞控最新参数自动查找 `RC_MAP_VEC_ROLL`、`RC_MAP_VEC_PITCH`、`RC_MAP_VECTOR_SW` 和 `RC_MAP_LEVEL_SW`，检查通道校准和重复映射。最新测试记录的配置为 CH13、CH14、CH7、CH8，模板支持按实际读回值自动映射。

完整模板检查 `MPC_MAN_TILT_MAX ≥35°`、`MPC_TILTMAX_AIR ≥20°`。含矢量速率的模板适配 MorphQuad 仿真模型的 ±35° 单轴行程，要求 `CA_MQ_ARANGE` 和 `CA_MQ_BRANGE` 都匹配 ±35°。启动前检查只读回参数，工具箱确认完整 RC 帧回传和输入健康后才执行脚本。
