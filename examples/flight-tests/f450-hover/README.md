# F450 起飞与稳定悬停联合测试

复用“PX4 启动”页拥有或核实的软件飞控、本机 F450 模型，以及工具箱现有的共享飞控测试引擎。
本入口不创建第二条 MAVLink 控制连接，不启动另一套模型，不修改飞控参数或绕过解锁检查。

当前执行环境的套接字绑定被拒绝，因此本次真实起飞和悬停为 **BLOCKED**，没有发送解锁/起飞指令。
`tests/f450-hover-acceptance.py` 的合成证据测试只验证判定逻辑，不能作为飞行通过证据。

## 上位机准备

使用当前源码构建的上位机，在本地配置启用内置 F450 仿真，重新打开后等待服务和软件飞控就绪。
打开 PX4 工具箱，选择实例 01，确认 F450_PX4 正在地面运行、软件飞控在线且未解锁。
联合测试要求 MCP 状态包含 `localSimulation`。内置模式可以直接使用；自定义本机模式须通过
`localPx4Matched` 核实软件飞控正在运行，且模型的本机 HIL 目标与 PX4 监听端口一致。
外部目标、旧构建、普通非 HIL 心跳以及缺失本地/全球位置的状态不会自动执行起飞。

如果同时报告 Accel/Gyro/Compass/barometer missing 和 ekf2 missing data，检查启动日志是否使用
`commander start -h`。本版本已修复 UDP HIL 启动入口；更新后先停止旧 PX4，再启动新进程。
仅设置 `SYS_HITL=1` 不会让这版 POSIX commander 自动进入 HIL。

定位正常但电机指令为零时，确认输出驱动使用 `pwm_out_sim start -m hil`，且 `PWM_MAIN_FUNC1..4`
映射到 Motor1..4。UDP HIL 启动入口会将 Gazebo 机型的 SIM_GZ_EC 电机映射迁移到空的 PWM_MAIN 槽位，
保留已有用户映射；更新后需要停止并重新启动 PX4。

`hover.xml` 可以直接导入工具箱“仿真测试”页查看积木流程。
依次执行：落地检查 → 普通 RC 输入 → 低油门 → POSCTL → 解锁 → 起飞 5m →
油门回中/POSCTL → 稳定 5s → 悬停 30s → 降落 → 确认落地 → 上锁。
完成与中止都使用共享测试引擎的降落策略。

## 通过条件

下列条件须在同一完整悬停窗口内满足；同时检查 PX4 估计值和独立 JSBSim 模型真值。
模型高度用试验开始前地面状态下的机体海拔作基线，水平漂移相对悬停开始的位置。

| 项目 | 条件 |
| --- | --- |
| 目标高度/持续时间 | 相对高度 5m，悬停至少 30s |
| 高度误差 | 所有有效样本绝对误差 ≤0.5m |
| 水平漂移 | 所有样本距悬停起点 ≤1m |
| 姿态 | 横滚、俯仰绝对值均 ≤5° |
| 水平/垂直速度 | 分别 ≤0.3m/s、≤0.2m/s |
| 证据完整性 | 飞控轨迹≥270点、最大间隔≤0.5s；模型真值≥45点、最大间隔≤1.1s；覆盖均≥28.5s |
| 模型运行 | 遥测年龄≤1s，模型时间持续推进，悬停窗口内模型时间覆盖≥28.5s |
| 收尾 | 测试 passed，并确认实际落地和上锁 |

这是本次功能验收阈值，不是通用机体飞行认证标准。
运行中连接过期、模型切换、姿态超过30°或离地高度超过12m，会请求共享引擎停止并降落。
程序不会因通信失联强行空中上锁；退出未确认会报告失败。

## 运行

在允许本机网络套接字的系统终端执行：

```sh
cd /home/qikai820/chatgpt_pro/jsbsim_nuttx/jsbsim-visual-editor
python3 scripts/test-f450-hover.py --run
```

仅收集当前状态并检查就绪条件，使用 `python3 scripts/test-f450-hover.py --diagnose`，不会发送飞行指令。
省略 `--run` 只生成 XML/计划，不控制飞控。
`--endpoint` 可指定当前上位机的 MCP 端点文件，`--output` 可指定结果目录。
默认使用标准用户应用数据目录下的端点；认证令牌不会进入报告。

结果位于 `diagnostics/f450-joint-<UTC时间>/`：`result.json` 为判定，
`report.json` 为共享引擎的完整分段轨迹，`scene-samples.json` 为独立模型真值，
`preflight.json`、`live.json` 和 `hover.xml` 用于核对目标及过程。
没有真实样本、使用 dryRun、缺失悬停标记、证据断档、模型时间冻结和未确认落地都会判失败。
权限或目标未就绪时退出码为 2，状态为 blocked，不会假报通过。
