# 飞控仿真测试工作台

## 完整四模式模板（2026-11-20）

内置模板默认选择“完整四模式”：手动、定高、普通定点、矢量定点四组均包含航向。手动/定高 Roll/Pitch ±35°、5°步进、保持 2 s，每点使用统一“回位”积木返回固定原点和零速；回位保持原模式。矢量 Roll/Pitch ±120°、10°步进、保持 10 s；普通定点用 ±60%主杆各 2 s 检查响应和刹停。航向相对统一基准 ±90°、30°步进，手动/定高保持 2 s 后回位，定点两组保持 10 s 并检查位置保持。

“回位”通过动作、适用模式、航向处理及容差参数区分原点记录、固定原点返回和仅刹停。连续稳定计时在任一条件偏离时重置。新增“航向步进”支持跨零点误差、转向速率限制、反馈显示和报告。文件与验证范围见 `examples/flight-tests/morphquad-attitude/README.md`。旧版九阶段和旧分项保留为兼容入口；新能力需要更新后的桌面程序。

入口：**工具 → PX4 工具箱 → 仿真测试**。测试动作通过现有仿真机 MAVLink 转发服务回传到 PX4，复用工具箱的 UDP 会话和源端口。电脑不另开飞控 USB 串口，也不增加一条飞控连接。

## 主输入来源切换

仿真测试工具栏在“设置”后提供来源一体按钮。使用 PX4 现有 `COM_RC_IN_MODE`：`0` 选择实体 RC 主输入，`1` 选择工具箱 MAVLink 主输入。其它取值显示“自动／混合输入”，点击可显式选择 MAVLink。仅在线、双向 HIL、已上锁、无测试时允许切换。参数只写一次，随后回读确认，不自动重试写入。

默认测试通道已改为标准 `MANUAL_CONTROL`。主杆、油门和 AUX1～6 直接使用归一化值，不再同时发送 `RC_CHANNELS_OVERRIDE`。切换到模拟时持续发送中位主杆、低油门；等待参数为 1 且飞控的 `MANUAL_CONTROL` 主杆回传匹配，连续确认 1 秒后显示就绪。切回实体时停止模拟发送，等待参数为 0、新鲜 RC 回传和输入健康。后台待机不依赖窗口可见性；真实测试接管发送，离线预演保持原有待机输入。断线、身份变化、HIL 退出或非测试期间解锁会结束待机，不跨连接自动恢复。

配套矢量固件只调整 `VectorPositionControl` 及输入辅助函数，不新增参数或自定义遥测。HIL 下独立 Roll/Pitch 允许 `manual_control` 已选择的 RC 或 MAVLink 来源，仍要求输入有效、新鲜及原有模式、解锁、离地、限幅等条件。实体路径保留 RC 映射；MAVLink 路径使用逻辑 AUX1/AUX2，`MANUAL_CONTROL.buttons` bit 0 为矢量开关、bit 1 为回平开关。矢量开关跟随已选中的 MAVLink 主输入，不再读取实体接收机的开关。非 HIL 保持既有来源限制。

“普通旋翼 / 矢量旋翼”逻辑开关积木在实时 MANUAL_CONTROL 模式中编码为标准按钮位；内置测试为普通和矢量阶段显式加入对应开关动作。它与“姿态输入路径”仍是两项独立设置。任意原始 RC1～18 动作不能通过 MANUAL_CONTROL 表达，实时执行在发送控制前明确拒绝；离线预演仍可编辑检查。高级调用可显式 `rcEmulation=true` 保留原始 RC 模拟路径，需自行满足飞控现有输入选择与校准配置。

旧 `HIL_RC_SRC` 参数方案及其固件改动已撤回，不再需要或请求该参数。切换功能使用现有 PX4 参数；矢量 AUX/开关支持需要本轮对应的矢量模块修改，不能把旧固件上的主杆切换视为矢量功能也已支持。

验证入口：`python3 tests/vector-manual-input-firmware.py`、`cargo test --manifest-path src-tauri/Cargo.toml --test flight_test --offline`、`node --experimental-websocket tests/px4-rc-source-ui.mjs`。本地策略、模拟 UDP 与隔离 IPC 结果不等于真实 HIL 或飞行验证。

## 编排与运行

桌面端的 PX4 工具箱是系统独立窗口，可自由移动、缩放、最大化或放到另一台显示器，主编辑器保持可操作。窗口记住上次的位置和大小；关闭窗口只隐藏，连接和测试继续保留。

编辑区默认只保留 52px 动作分类栏，属性、模板、设置、文件菜单和执行记录按需展开。点击左侧分类展开动作库，可点击添加，也可拖到画布插入位置；宽窗口临时为动作库让出空间，便于拖放。拖动积木左侧的点阵手柄可调整顺序或移入分支。选择积木后，右侧展开完整参数、上移、下移、复制、删除；文件菜单提供撤销、导入、保存 XML、运行记录和新建模板，编辑区的 Ctrl/Cmd+Z 也可撤销。

**参数 / 运行监控** 分页显示参数与反馈，窄窗口将详情变为右侧浮层。**专注画布** 收起工具箱页签、动作栏和属性，保留编辑工具与底部状态；Esc 可退出专注或关闭当前展开的面板。重复、条件和并行积木支持折叠内部流程，折叠仅改变显示，不修改脚本。底部常驻状态、运行时间和终止，执行记录默认收起；停止请求期间显示退出确认状态。

顶部 **模板 → 内置测试** 的 MorphQuad 完整测试采用九阶段：手动油门起飞 → 普通主杆 MANUAL（每点 2 s 后手动回位零速）/ ALTCTL（每点 10 s）的 Pitch、Roll ±45°（5°步进）→ 普通 POSCTL 双轴 ±60%主杆各打杆 2 s 并检查倾斜、移动及回中刹停 → 矢量 Position AUX2 Pitch、AUX1 Roll ±120°（10°步进）→ 降落并确认上锁。普通阶段明确关闭逻辑 Vector，矢量阶段开启；新增定点专项模板用于先复查这两条控制路径。选择高度后点击“载入脚本”即可显示循环积木。旧工作区保留，可显式载入新版并撤销。加载不启动飞控。

- 飞控动作：模式、解锁、上锁、起飞、降落。
- 遥控输入：单轴打杆、多轴打杆、姿态回中、基准油门、油门控高、手动油门起飞、手动回位制动、姿态输入路径、姿态角步进和增量。
- 流程控制：等待、等待状态、检查、有限次数重复、条件分支、并行、事件标记。

普通动作使用紧凑拼接形状，条件使用六边形，重复和条件分支使用包围结构，并行使用横向分支和汇合条。动作参数可直接在积木上修改，运行时高亮活动积木，右侧显示杆量，底部显示执行事件与退出结果。

默认模板用于**已经处于悬停状态**的仿真机：切换 POSCTL，横滚 20% 持续 3 秒，同时偏航 −15% 持续 1.5 秒，然后等待 1 秒。模板不自动解锁或起飞；默认油门杆为 50%，这只是归一化杆位，不保证任意机型或模式悬停。测试设置可修改基准油门、时钟、频率、总时限和退出策略。

横滚、俯仰、偏航范围为 −100%～100%，油门为 0%～100%。默认通过 `MANUAL_CONTROL` 直接发送标准化主杆和 AUX1～6，逻辑矢量开关使用按钮位；不并行发送原始 RC 覆盖。高级 `rcEmulation=true` 路径才按 `RC_MAP_*` 与 `RCn_MIN/TRIM/MAX/REV` 还原完整 RC 帧，保留原有校准和映射语义。动作结束后对应轴回到基准值，等待期间继续发送基准杆量。

### 通道控制与旋翼模式开关

在“遥控输入”动作库添加 **通道控制**，选择 RC1～RC18、AUX1～AUX6，或“矢量模式开关（自动映射）”。积木内与右侧属性面板均输入 −1～+1 的归一化浮点数（例如 −0.25、0、0.5），0 为中位；动作可选“设置并保持”或“释放本通道”。已有脚本自动按此单位显示，输出含义保持一致。设置积木完成后立即继续流程，通道值跨越等待、循环和后续动作持续发送，直到另一个通道积木改值、释放或测试退出。因此切换应放在并行组外，再进入并行控高/姿态测试。

右侧快捷按钮 **普通旋翼** / **矢量旋翼** 仍使用同一个逻辑开关积木，分别设置 −1 / +1。默认 MANUAL_CONTROL 路径将其转换为按钮 bit 0，不依赖实体 RC 通道编号；高级原始 RC 路径才读取 `RC_MAP_VECTOR_SW` 并按校准输出。回普通模式的回平和舵机交接仍由固件完成。内置测试已显式插入普通/矢量开关；旧脚本需自行添加所需开关动作，姿态输入路径仍独立选择。发送开关命令不等同于实际模式转换已经完成。

示例：`通道控制 → 普通旋翼` → 普通主杆测试 → `通道控制 → 矢量旋翼` → `姿态输入路径 → 矢量 AUX` → 矢量姿态测试。通道控制与姿态输入路径分别控制飞控开关和脚本输入选路，二者可独立编排；原有内置脚本不会被自动插入开关积木。

- 高级原始 RC 兼容路径使用 `RC_CHANNELS_OVERRIDE`，根据本次读取的 `RCn_MIN/TRIM/MAX/REV` 换算，支持反向和非对称校准。PX4 将该消息作为完整 RC 采样，默认不再并发发送 `MANUAL_CONTROL`。启动时一次请求 `RC_CHANNELS`，未被主杆/AUX/通道积木占用的通道保留取得的新鲜有效原始值，缺失时采用校准中位；释放原始 RC 通道后回到该起始值。AUX 释放后回中。主杆心跳持续至测试退出。原始 RC 通道与已映射主杆/AUX 的重复控制会明确报冲突。退出回中、Hold 和降落继续使用同一 RC 输入来源，停止后由飞控超时处理。
- 原始 RC 模拟兼容路径不限制 `COM_RC_IN_MODE`。默认 MANUAL_CONTROL 路径会读取并确认参数为 1；只有用户点击来源按钮时才写入 0 或 1，测试启动不会隐式修改参数。
- AUX1～AUX6 是逻辑功能名称：默认直接使用 MANUAL_CONTROL 扩展字段；原始 RC 兼容路径按 `RC_MAP_AUX1`～`RC_MAP_AUX6` 映射到物理通道。矢量姿态控制占用 AUX1 / AUX2，同一通道仍被通道积木保持时会报冲突，须先显式释放。退出时六个 AUX 均发送零值。
- 离线预演的自动映射使用示例 **RC8**，不会读取或发送设备指令；实时映射始终来自飞控。运行记录的 `test/output/rcN-norm`、`test/output/auxN-norm` 保存设置通道的输出值，右侧杆量区同步显示。

**离线预演**使用示例遥测和模拟命令确认，以约 4 倍速度检查执行顺序、并行合并、超时与退出，不发送设备指令，也不运行飞机动力学。实际执行在 Rust 后台线程调度，界面只轮询显示状态；切换页签不会停止后台调度。

## 在飞行视景中观察测试

在工具箱载入脚本后，点击 **视景观察**，进入飞行视景的简洁测试浮层；也可通过视景左侧 **测试** 按钮显示或隐藏。视景和工具箱共用同一个后台测试、已固定的 UDP 会话和运行状态，不另开连接或重复启动测试。

- **简洁显示**：显示脚本名、绑定实例、当前动作、并行任务摘要、姿态连续保持进度和已运行时间。未运行时可执行已载入脚本或离线预演，沿用工具箱的执行前提；脚本编排与 XML 草稿仍在工具箱处理。
- **展开详情**：显示活动任务、姿态/高度目标与实测反馈、杆量及最近四条事件。详情内容可滚动，底部操作区保持可见。原始 XML 没有可视积木映射时，使用反馈属性或活动节点标识，不猜测步骤百分比。
- **隐藏**：只收起浮层，后台测试和连接继续保留。底部显示运行状态、时间和 **终止**；点击状态条或左侧“测试”可恢复简洁显示。显示方式保存在本机，离开视景再返回也能恢复。

“专注”、场景编辑或左侧其他面板打开时，测试浮层暂时收起，底部仍保留状态与终止入口。窄窗口优先保留测试浮层和底部数值，暂时收起重叠的小地图与圆形 HUD；隐藏浮层后恢复原有显示设置。

关闭工具箱现在只隐藏界面，保留连接与工作区。运行期间切换观察实例不会改变测试绑定或重建连接；浮层明确显示正在测试的实例，并可一键切回观察该实例。终止后先显示 **确认退出状态**，再展示后台实际返回的退出结果；请求失败保留错误及终止重试入口。关闭整个应用仍会请求终止。

## 油门控高

从左侧“遥控输入”添加 **油门控高**，设置目标相对高度（默认 5 m）和持续时间（默认 20 s）。模块读取飞控高度及向上为正的升降速度，持续调整映射到 RC 油门通道的杆量；高度低时推杆、高时减杆、接近目标时制动并保持。它不发送 Offboard 高度目标或直接电机输出。

- `ALTCTL / POSCTL`：在 50% 中位附近请求升降，补偿中位死区，接近目标后回中。
- `MANUAL / STABILIZED`：围绕可配置的悬停杆位微调推力，用慢速积分修正悬停杆位偏差。需要按模型检查悬停杆位和响应参数。
- 仅占用油门轴，可与横滚、俯仰、偏航单轴打杆并行。不能同时使用另一条油门动作或占用全部四轴的“多轴打杆”。
- “控高调节”提供油门上下限、杆量变化速率、高度响应、升降制动、慢速修正和中位补偿。默认杆量限制 25%～75%，变化率 25%/s；回中范围是控制死区，不是高度精度保证。
- 右侧显示目标高度、当前相对高度、高度误差、升降速度和实时发送油门。运行记录包含同样的反馈数据。
- 先解锁并进入支持的模式，建议先完成起飞再控高。持续时间包含接近目标和保持；结束后释放油门轴，恢复测试基准杆位，再按所选退出策略处理。飞行模式变化、解锁状态不符或高度/升降速度反馈缺失与过期会终止测试并执行退出策略。

例如从地面开始保持在 5 m 附近：`模式 POSCTL → 解锁 → 起飞 5 m → 模式 POSCTL → 油门控高 5 m / 20 s`。已经悬停时直接执行控高积木即可；需要一边打杆一边保持高度时，将控高和其他独立轴放入同一并行组。实时执行要求 HIL 及运行中的仿真实例，不限制 `COM_RC_IN_MODE` 的取值，不自动改参数。

控高期间按需以约 10 Hz 请求高度和升降速度消息，不修改飞控持久遥测配置。离线预演的示例高度不会随杆量变化，仅用于检查流程和显示；控制效果需在目标模型的闭环仿真中验证。

## MorphQuad 姿态角步进

“姿态输入路径”区分普通主杆与矢量 AUX，必须在并行输入组之外切换。普通路径在手动、定高使用主杆做 ±45°姿态测试；普通 Position 主杆表达水平运动请求，内置脚本用打杆及回中刹停检查，不能用持续角度保持作为普通定点判据。矢量路径仅在 Position 使用 AUX1=Roll、AUX2=Pitch；通用编辑器允许编排 ±140°，当前 MorphQuad 内置脚本按飞控代码限制为 ±120°。增量动作相对上一目标累加，可放入循环。

“手动油门起飞”在已解锁的 MANUAL 模式使用实际油门爬升，不发送自动起飞指令。默认爬升速度指令上限 0.5 m/s，油门缓升 10%/s，离地后达到高度范围并稳定 3 s 才完成；结束时把实际油门交给基准杆位。完整脚本包含低油门解锁、电机启动等待、地面/已离地分支及安全交接。该模块占用四轴，不能与其他打杆动作重叠。

“回位”统一支持 MANUAL / ALTCTL 原点返回，以及 POSCTL 刹停；通过参数选择。手动原点返回的原有算法：每轴先“记录本轮原点并稳住”，每次角度激励后“回到本轮原点”。先制动，再低速返回，默认位置误差 ≤0.5 m、水平速度 ≤0.2 m/s，并满足姿态/高度条件连续稳定 2 s 后完成。返程速度上限 3 m/s、倾角上限 20°，水平加减速上限 3 m/s²、倾角变化上限 30°/s，回位时限 120 s；与油门控高并行，不切换 Position。制动末段低速时及近原点低速时采用有界速度积分补偿姿态估计偏差或恒定扰动，补偿加速度向量不超过 0.5 m/s²；高速制动和长距离返程时冻结积分，避免激励累积。原点固定到下一次显式记录，回位不清除循环累计的角度目标。新版完整脚本的普通手动激励保持 2 s、每点后插入回位；定高和矢量姿态点保持 10 s；普通定点使用 2 s 打杆和回中刹停检查。

“姿态角步进/增量”占用姿态三轴，与油门控高并行。四元数反馈达到姿态、高度和角速度条件后稳定 0.5 s，再连续保持 10 s；矢量 Position 额外检查水平位置，普通 Position 允许打杆引起的位置变化。普通辅助模式用姿态反馈修正主杆，报告输入饱和。

不新增或查询自定义固件能力参数。普通路径按当前倾角等参数换算杆量；HIL 矢量路径需要本轮矢量模块支持，允许有效新鲜的选中 MAVLink 输入及其逻辑开关、AUX。原始 RC 兼容路径仍能满足传统 `SOURCE_RC` 条件。非 HIL 的输入来源条件保持既有行为。实际可达角度由当前机型固件及配置限幅决定，未到位如实超时，不通过放宽完成判据伪造成功。

## 并行规则

每组支持 2～4 个分支，可嵌套分支、重复和条件。

| 规则 | 行为 |
| --- | --- |
| 全部汇合 | 等待所有分支完成，再执行后续动作 |
| 任一汇合 | 第一个分支完成后，取消其余分支的后续动作和活动输入 |
| 独立轴 | 横滚和偏航等不同轴可以同时打杆，合并成一帧遥控输入 |
| 同轴冲突 | 同一时刻两个分支占用同一轴会终止测试；不使用隐式覆盖 |
| 油门控高 | 占用油门轴，可与其他独立轴并行；结束或取消分支会释放控高状态 |
| 分时复用 | 不同时段的同轴动作可以放在不同分支 |
| 状态指令 | 飞控模式、解锁、起飞等状态指令应串行执行，不能与打杆或另一个状态指令重叠 |
| 基准油门 | 只能在串行流程修改；并行内用多轴或单轴油门动作限定持续时间 |

已经被飞控接受的指令不能由“取消分支”撤回。后台会等待被取消的在途指令确认，再允许后续状态指令；3 秒仍不确定则终止测试。飞控拒绝指令、条件超时、并行组超时或总时限到达但流程未完成，都会显示失败。

条件分支在进入时读取最新状态并锁定选择；缺少或过期遥测时不擅自走“否则”。等待状态和检查均等待条件在指定超时内满足。循环为 1～20 次，最多 400 个可视积木、8 层嵌套，展开后最多 1024 个执行节点；总时长最多 14400 s。

## 实际飞控执行条件

1. 现有仿真机转发服务在线且双向可用，工具箱已经识别并固定 PX4 的 SYS/COMP 与 UDP 回传来源。
2. 飞控心跳已确认 HIL 模式，所选仿真实例正在运行，遥测新鲜。
3. 默认 MANUAL_CONTROL 路径需要 `COM_RC_IN_MODE=1`；参数只由用户点击来源按钮切换，测试不会自动改写。原始 RC 兼容路径才要求 RC 校准、四轴/AUX/矢量开关映射完整且不冲突。
4. 当前没有参数写入、仿真模式切换、日志下载等独占操作。启动测试会关闭已有 MAVLink NSH 会话，退出后可重新进入 NSH。

默认 MANUAL_CONTROL 在脚本前发送中位主杆及适当的基准油门，等待参数为 1 且飞控选中主杆的回传匹配，连续确认 1 秒后开始。

原始 RC 兼容路径在执行脚本前先准备输入：地面且上锁时持续发送中位主杆、低油门和零 AUX，保留有效开关基准；等待新的 `RC_CHANNELS` 与发送帧完全匹配、`SYS_STATUS` 遥控输入存在且健康，连续确认 1 秒才将脚本置为 ready。最多等待 6 秒；回传不匹配、来源竞争或反馈过期会重新计时，未就绪不执行模式、解锁或起飞积木。准备阶段界面明确显示“正在准备遥控器”，终止仍有效；已在空中时按脚本基准油门接管，失败按异常退出策略处理。既有固件健康检查继续决定能否解锁，不读取或修改输入选择参数来绕过它。

所有脚本（包括 RC、AUX 和自动映射开关）均不限制 `COM_RC_IN_MODE` 的取值（包括 `3`），也不读取该参数作为启动条件、在运行期间轮询或自动修改它。主杆与 AUX 均走同一 RC 输入来源，输入的选择与处理由飞控当前配置决定。`COM_RC_IN_MODE=1` 只接收 MAVLink 摇杆、`4` 禁用手动输入，不会因此接受本模拟器的 RC 主杆；未设前置限制不代表所有配置都能响应。执行时应只有一套持续更新的 RC 通道源；物理接收机与模拟 RC 同时发布会导致 `input_rc` 来源交替，不能依靠输入选择参数区分这两个 RC 发布者。

实时测试绑定启动时的会话、SYS/COMP、仿真实例、模型和场景代次，并记录可取得的飞控硬件 UID。HIL 状态丢失、飞控重启/失联、目标变化、模型重载、仿真暂停、时钟倒退或停止推进都会终止测试。当前使用单个转发飞控目标；选择场景实例只确定仿真状态和时钟来源，**不自动建立多实例与多飞控的对应关系**。

默认采用真实时间，适合实时 HIL；可选所选实例的仿真时间。控制帧按真实时间持续发送，频率为 20～100 Hz，默认 50 Hz。场景暂停不会保持无限期打杆。

飞控命令需要 **COMMAND_ACK 接受 + 后续实际状态** 同时确认：模式/解锁由新心跳确认，起飞还需新高度和离地状态，降落需落地状态。上锁要求最新落地确认，不发送强制解锁或强制上锁参数。测试不修改飞控的持久遥测发送频率，按需请求状态报文。

## 退出与记录

正常结束、失败/终止可分别配置：

- **Hold**：姿态三轴回中并保持当前基准油门，发送 Hold 请求，取得 ACK 和模式确认后停止输入流。
- **降落**：发送降落请求并确认模式，继续保持中位遥控输入和 GCS 心跳，等待新鲜着陆状态；着陆后发送普通上锁请求或确认飞控已自动上锁，再停止输入。最多等待 120 秒，不发送强制上锁指令。完整 MorphQuad 测试默认使用该策略。
- **释放输入**：发送最后一帧回中杆量后停止输入流。后续行为由 PX4 输入失联配置决定。

已确认上锁的飞控直接停止输入流。有在途飞控指令时，退出前先额外等待最多 3 秒核实结果，避免把指令发出前的上锁状态当成最终状态。随后退出模式确认最多等待 3 秒，期间继续发送回中杆量；降落策略额外等待实际着陆与上锁，期间维持输入链路；失联或未确认会明确报告失败，停止发送，不宣称退出成功。飞控身份变化后连回中帧也不再发送。隐藏工具箱或测试浮层不终止测试；关闭整个应用会请求终止并等待执行线程退出。

“保存运行记录”导出 JSON，包含原始 XML、执行设置、开始时间、目标绑定、最终结果、事件日志和杆量/飞控状态轨迹。事件最多保留最近 2000 条，轨迹最多 40000 点。采样间隔为 `max(0.1, end / 39999)` 秒，长流程自动降低记录频率以覆盖全程，实际间隔写入 `traceIntervalSeconds`。下一次运行会替换内存中的上一次记录，应及时保存。

## JSBSim XML 兼容范围

积木编译为普通 FGScript：`runscript / use / run / property / event / condition / set / function / notify`。并行、循环和分支通过属性与事件展开，XML 中不增加自定义 `<parallel>`、`<loop>` 或 `<await>` 标签。导出的流程已用真实 JSBSim `FGScript` 加载和执行验证。

飞控工作台执行的是**控制测试叠加脚本**：动力学仍由现有仿真机运行，`test/*` 属性由桌面后台提供飞控桥接。这里的 `<use aircraft="..." initialize="..."/>` 是机型/初始化标签，不会重载或复位当前模型；`run dt` 保留为 XML 元数据，控制调度由后台线程完成。直接操纵任意 `fcs/*`、气动或模型属性的完整 JSBSim 脚本，应使用原有仿真脚本入口。

支持导入/编辑的事件子集：

- `run start="0"`，`end` 为 0.02～14400 秒；脚本不超过 4 MiB。
- `condition logic="AND|OR"` 及嵌套条件；`ge/le/gt/lt/eq/ne` 或对应比较符号。
- `set` 常量或函数值，`STEP/RAMP/EXP` 动作，`VALUE/DELTA/BOOL` 类型，`tc`、事件 `delay`、`persistent`、`continuous`。
- 函数：`value`、`property`、`sum`、`difference`、`product`、`quotient`、`min`、`max`、`abs`。
- `notify`、`description`、带 `caption` 的 `property`，写入事件日志。

不支持的标签、属性、函数和模型属性会在校验时明确拒绝；不静默忽略。禁止 DTD/外部实体。事件按 XML 顺序执行，同一轮完成后再合并杆量。

主要属性接口如下，数值使用 SI 单位及归一化杆量：

| 属性 | 说明 |
| --- | --- |
| `simulation/sim-time-sec` | 从测试起点计算的所选脚本时钟，只读 |
| `test/runtime/ready` | 后台检查通过后置 1，只读 |
| `test/runtime/complete` / `failed` | 脚本置 1 表示完成/失败 |
| `test/rc/input-kind` | 姿态输入路径：0 兼容旧脚本、1 普通主杆、2 矢量 AUX；不写飞控参数 |
| `test/channel/{vector-switch,rc1…rc18,aux1…aux6}/{enabled,value-norm}` | 通道保持开关（0/1）及归一化输出（−1～1）；每次测试从未保持开始 |
| `test/output/{rc1…rc18,aux1…aux6}-norm` | 当前通道积木保持的实际输出，只读；自动映射开关解析为 RC 通道 |
| `test/rc/enabled` | 是否持续发送遥控输入，0 或 1 |
| `test/rc/{roll,pitch,yaw,throttle}-norm` | 基准杆量，姿态 −1～1，油门 0～1 |
| `test/input/名称/enabled`、`mask`、四轴 `*-norm` | 临时打杆作用域；mask 为横滚 1、俯仰 2、偏航 4、油门 8，按位组合 |
| `test/input/名称/height-*` | 控高配置：target-m、tolerance-m、hover-norm、min/max-norm、slew-norm-s、kp/kd/ki、deadzone-norm；由桌面属性桥执行反馈控制 |
| `test/altitude/名称/status` | 手动油门起飞稳定完成后为 1，只读 |
| `test/input/名称/recover-*` | 手动回位的原点操作、位置/速度容差、稳定时间、返程速度、倾角、加速度和变化率 |
| `test/manual/名称/status` | 手动回位稳定完成后为 1，只读 |
| `test/manual/{字段}` | 字段为 `active`、`phase`、`position-error-m`、`speed-mps`、`held-s`；各自为独立只读路径 |
| `test/fc/local-vx-mps`、`local-vy-mps` | 最新 LOCAL_POSITION_NED 的北/东速度，缺失或过期不参与回位 |
| `test/input/名称/height-climb-max-mps`、`height-settle-s` | 手动起飞爬升速度指令上限、稳定时间 |
| `test/altitude/{active,target-m,error-m,throttle-norm,holding}` | 控高反馈，只读，写入运行记录 |
| `test/target/{roll,pitch}-deg` | 连续姿态目标，供增量循环累加；编译器生成 |
| `test/input/名称/angle-*` | 姿态角配置：roll-deg、pitch-deg、hold-s、tolerance-deg、rate-deg-s、settle-s |
| `test/attitude/名称/status` | 该姿态点连续保持完成后为 1，只读 |
| `test/attitude/{active,roll-target-deg,pitch-target-deg,error-deg,held-s,position-error-m,aux1-norm,aux2-norm}` | 姿态目标、误差、保持进度、定点水平偏移与 AUX 输出，只读 |
| `test/fc/q1`～`q4`、`{roll,pitch,yaw}-rate-rad-s` | 四元数和机体角速度，只读，250 ms 过期 |
| `test/attitude/input-range-deg` | 当前模式用于杆量换算的满杆角度范围，只读 |
| `test/fc/local-{x,y,z}-m` | 本地 NED 位置，只读，定点扫描检测水平偏移 |
| `test/fc/climb-rate-mps` | 升降速度，向上为正，只读；由 GLOBAL_POSITION_INT 的 NED vz 换算 |
| `test/command/名称/kind`、`argument`、`request` | kind：解锁 1、上锁 2、模式 3、起飞 4、降落 5；request=1 发起一次指令 |
| `test/command/名称/status` | 后台确认后置 1，只读；初值只能为 0 |
| `test/fc/armed`、`hil`、`landed` | 飞控状态，只读，0/1 |
| `test/fc/mode` | 模式代码：MANUAL 1、ALTCTL 2、POSCTL 3、HOLD 4、ACRO 5、OFFBOARD 6、STABILIZED 7、LAND 8、TAKEOFF 9 |
| `test/fc/relative-alt-m`、`altitude-msl-m` | 相对高度和海拔高度，只读 |
| `test/fc/{roll,pitch,yaw}-deg`、`{roll,pitch}-abs-deg` | 姿态角/绝对值，单位度，只读 |
| `test/fc/groundspeed-mps` | 地速，只读 |
| `test/flow/名称/{started,done,cancelled,deadline,choice}` | 编译器生成的流程状态 |

脚本须先用 `<property value="...">路径</property>` 声明可写属性。原始 XML 每个状态指令使用独立名称；同名 `request` 一次运行只处理一次。未使用 `test/runtime/complete` 的原始 XML 到达 `run end` 后结束；可视流程要求显式完成，否则按超时失败处理。

保存 XML 时附带可视布局元数据，重新导入未改动的文件可恢复积木。手工修改 XML 后，若与积木不再一致则保留完整原始 XML 并使用 XML 模式运行；不会用旧布局覆盖改动。未应用的 XML 草稿禁止运行，积木、原始 XML 和草稿均保存到本机。

### 手动模式复测的链路与参考检查（2026-11-18）

手动普通姿态扫描在倾角超过 60°、体轴角速度超过 120°/s 或高度偏差超过 min(目标高度的一半, 3 m) 时停止后续激励，与回位模块的边界一致。地面手动起飞还要求新鲜相对高度在 ±1 m 内；模型重建后残留上次飞行的高度原点会导致预检查失败，须先对齐当前地面模型与飞控高度参考。

原生执行器复用已有新鲜反馈，仅为缺失消息逐条配置周期并确认回执，代替飞行中的高频单次查询。身份每 5 秒查询一次。退出时仅在同一身份、同一会话代次、心跳/HIL 有效且已上锁时恢复本次新增流的默认周期；已解锁时保留反馈，不在身份改变或链路断开后发送收尾配置。这不写入飞控参数。链路调整需要结合 HIL 对照结果判断，单元测试通过不能代替飞行验证。

命令行入口在视觉 UDP 5801 空闲时负责原有视觉心跳与接收，避免桌面关闭后触发仿真机 10 秒超时；已有桌面监听时继续只读抓取。状态文件每 250 ms 更新，终端摘要保持每 5 秒输出。完整报告仍保留脚本、实际绑定、完成事件、轨迹和退出确认。

手动回位从上一激励指令连续接管，倾角变化限速覆盖交接首帧。回位倾角上限约束制动/返程目标，不会先把 45°激励指令直接裁成回位限位。2026-11-18 的同固件 HIL 对照中，旧版约 74.7 Hz 单次查询在 0°目标下复现了振荡；复用已有流、仅 0.2 Hz 身份查询的版本完成 Pitch/Roll ±5°、±10°共 18 点，19 次回位（含原点稳定）全部达到 0.5 m / 0.2 m/s / 连续 2 s 的判据。±45°及后续阶段仍须单独完成 HIL 验证，不能据小角度结果宣称全部通过。

普通 MANUAL 的短激励在姿态到位并稳定后计时，油门控高持续运行，但不等待高度收敛再开始两秒停留，避免长时间加速。每点后的回位仍须满足位置、速度、姿态和高度全部判据。切换 Hold/Land 前连续回中 0.8 s，让 PX4 的摇杆变化率滤波收敛，再请求自动模式；自动模式交接及降落期间维持中位油门和输入心跳，保留原有飞手接管保护。

## 兼容调用

桌面工作台、MCP 和 CLI 默认采用 `MANUAL_CONTROL`（启动选项 `rcEmulation=false`，省略时也默认为 false），实时执行要求 `COM_RC_IN_MODE=1`。高级集成可显式传 `rcEmulation=true` 使用完整原始 RC 模拟；该路径与按钮的 MAVLink 主杆切换分开，不能代替主输入来源选择。此模拟覆盖 PX4 接收原始通道后的校准、映射及选择链路，不覆盖真实接收机、射频或 SBUS/CRSF 硬件传输。
