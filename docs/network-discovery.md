# 仿真机网络自动接入

编辑器在网络模式下自动接收仿真机数据。默认遥测端口为 UDP 5801，控制端口为
UDP 5802，发现端口为 UDP 5803，不需要单独的连接按钮。

## 发现与重连

- 发送 `JSBSIM-DISCOVER` 时，除了全局广播，还覆盖每个已启用的有线 IPv4
  私有子网，包括同一网卡的多个地址。Wi-Fi 占用默认路由不会漏掉有线网段。
- 未连接且没有显式设置 `SIM_UDP_HOST` 时，每五秒发送只读 `VCMD 7` 心跳探测。
  目标包括已学习地址、有线 ARP 邻居和有线子网广播。
- 兼容未启用 UDP 广播或发现应答的固件：仅在电脑有线网卡具有对应子网时，
  补充探测 BSP 的默认地址 `192.168.3.82`（i.MX93）和
  `192.168.101.82`（Orange Pi）。不遍历整个 IP 范围，也不要求已有 ARP 条目。
- 心跳探测复用遥测接收套接字，兼容把应答发回来源端口的固件。接收到有效
  遥测后，按来源 IP 更新后续控制目标，并每秒维持心跳。FTP 验证仍可识别
  只有 ROMFS 内置模型库的仿真机。

电脑必须为所接网口配置相同子网的地址；发现机制不会更改电脑或仿真机 IP。
`SIM_UDP_HOST` 可显式指定目标，`SIM_UDP_CTRL_PORT` 可覆盖默认控制端口；
编辑器遥测接收端口固定为 5801。

## Orange Pi 双网口

当前 Orange Pi HIL 启动配置只自动配置并启用 `eth1`，地址为
`192.168.101.82/24`。另一个 `eth0` 默认没有 IPv4 地址，不能直接当作
`192.168.3.82` 使用。以板端 `ifconfig` 的地址、运行状态和收发计数判断，
指示灯常亮本身不能证明 IP 网络正常，也不能单独证明硬件损坏。

## 验证

```bash
cargo test --manifest-path src-tauri/Cargo.toml --test network_discovery
cargo check --manifest-path src-tauri/Cargo.toml
```

回归覆盖多子网、接口过滤、无 ARP 时的默认地址选择及 UDP 心跳来源端口。
2026-11-09 实板核对了 `192.168.101.82` 的 FTP、NSH 和双向 UDP 通信；
新编辑器实际向各有线子网发送发现广播，并持续接收健康心跳、任务统计及
飞控状态。该轮没有重启或更新仿真机固件。
