# 电脑端模型仿真

入口：**本地配置 → 电脑端模型仿真**。

## 内置仿真

点击 **启用内置仿真**，退出并重新打开一次上位机，即可使用随安装包提供的 F450 四旋翼模型和 PX4 软件飞控。
无需选择工程/构建目录、填写 IP 或端口，也无需安装 Python。
上位机自动加载 `F450_PX4_lan.xml`，以地面初始状态运行；不会自动解锁或起飞。
退出上位机时收尾模型日志并停止本次软件飞控及模型服务。

内置资源包含原生 JSBSim 运行程序、PX4、模型库、Python 标准运行环境及所需共享库。
Python 负责已有的 FTP、兼容 NSH 和服务监督；动力学与飞控计算仍由 C/C++ 进程执行。
当前发行目标为 x86-64 Linux。资源安装到当前用户的应用数据目录，无需管理员权限。
升级使用新的版本资源目录；模型编辑和日志保留在独立的工作目录。
首次会复制模型库，后续只补充缺失文件，已有编辑不被覆盖。

当前会话的连接目标固定，启用/停用或切换运行方式均在重新打开上位机后生效，页面会提示。
已有自定义配置自动按原方式读取，不会因升级切换到内置预设。
启用内置预设也保留原来的自定义目录、地址和端口，切回“自定义”即可继续编辑使用。
已有编辑器画布保持；全新空画布在服务就绪后自动打开 F450 模型。

| 内置连接 | 地址 |
| --- | --- |
| 模型控制 UDP | 127.0.0.1:15802 |
| 上位机遥测 UDP | 127.0.0.1:5801 |
| 模型文件 FTP / 兼容 NSH | 127.0.0.1:2121 / 2323 |
| PX4 HIL 接收 / 模型执行器接收 | 127.0.0.1:14561 / 14560 |
| PX4 工具箱数据 | 127.0.0.1:14553 |

机型为与 F450 几何和电机顺序对应的 `3010_jsbsim_quadrotor_x`，PX4 实例 0。
软件飞控页可查看自动启动的进程、日志和停止状态。
端口占用、组件缺失或进程退出会显示具体错误，不会改连外部仿真机，也不会结束其他应用的进程。
“服务已就绪”表示模型/文件服务和软件飞控进程运行，起飞及闭环稳定性仍须单独验证。

## 自定义运行

在“运行方式”选择 **自定义 · 目录与连接参数**，继续使用已有 JSBSim 工程和 PC 构建。
需要先编译 `jsbsim_realtime/boards/pc/x86_64/pc.sh build`，填写工程和构建目录及 HIL 目标，保存后重新打开上位机。
自定义运行服务等待用户从仿真菜单选择模型/脚本，不自动启动 PX4。
可在软件飞控页选择自己的 PX4 构建目录与参数，或连接外部飞控。
关闭电脑端模型仿真后，下次启动使用原有的开发板连接。

原有“允许写入仿真机模型”选项同样控制本机模型库写入；当前仅支持实例 01。
本机服务启用时暂停开发板发现和 USB 仿真通道，只接受本机遥测。

## 开发和发行打包

开发环境先生成一次资源，普通用户的安装包已包含这些内容：

```sh
npm run prepare:simulation
```

资源生成器使用现有 `jsbsim_realtime/build/x86_64` 与工作区 `build/px4_sitl_default` 编译产物，
不在用户电脑启动时编译，也不联网下载。构建发行包前会自动执行该步骤。
支持 `scripts/package_builtin_simulation.py --project ... --px4-build ...` 供发行构建使用其他源码/构建。
生成资源位于 `src-tauri/resources/builtin-simulation`，由 Tauri 资源映射随包分发。
二进制构建目录及 Python 打包环境属于发行构建机，运行时不依赖它们的绝对路径。
生成器只修改资源副本，不修改原工程或用户模型库；复制的许可证放在资源的 `licenses` 目录。

验证命令：

```sh
cargo test --manifest-path src-tauri/Cargo.toml --test local_sim --test local_sim_target --offline
cargo test --manifest-path src-tauri/Cargo.toml --test local_sim real_payload_runs_after_relocation_without_system_python_packages --offline -- --ignored
node --experimental-websocket tests/local-simulation-ui.mjs
npx tsc --noEmit
npm run build
```

配置、资源安装、升级保留、自定义兼容、进程清理及真实资源迁移可在无网络环境验证。
界面、FTP/UDP 以及真实 PX4 闭环需要允许本机套接字；受限环境中的编译和资源验证不能代替这些联调。
