# 模块注释（停用）

右键点击模块，选择“注释模块（停用）”；再次右键可“取消注释（启用）”。
已注释模块灰显、显示虚线边框和“已注释”标记，保留位置、参数及连线。
属性面板可查看原参数，取消注释后才能修改。灰色虚线只表示原有连接，不会把输入自动直通到输出，也不会把输出替换为零。

支持范围：

- 主画布的系统和飞控模块。外部模块只注释主文件中的引用，不修改共享系统文件。
- 系统／飞控信号画布中的完整组件、函数和 FCS 函数。
- 从组件右键菜单注释／取消注释其所在的整个通道。通道中的独立停用状态会保留；恢复通道不会启用此前单独停用的组件。
- 气动系数画布中的完整函数。模块画布中展开的函数子图算子及派生查表块可通过菜单注释所属函数，不能独立移除表达式的必要操作数。

所属模块或通道被注释后，其内部内容为只读。先恢复所属模块／通道，再单独恢复组件。
主画布和属性面板提示当前已识别的下游信号依赖；这些检查基于编辑器能识别的属性引用，无法证明模型所有动态引用都有效。

注释／取消注释是结构修改，需要“保存到仿真机”并重新加载模型后生效。
编辑器不会把已停用组件的数值修改实时发送到运行实例；画布状态不能代表当前运行模型已经重载。

## XML 格式与恢复

可读内容使用带版本标记的标准 XML 注释：

```xml
<!-- jsbve-disabled:v1 encoding="plain"
<pure_gain name="fcs/test"><input>fcs/cmd</input><gain>2</gain></pure_gain>
-->
```

原内容包含 XML 注释或其他 `--` 时，封装为 `encoding="base64"` 的 UTF-8 内容，以避免非法嵌套注释。
JSBSim 只会看到一条注释，不会创建该组件。编辑器识别专用标记，重新打开时恢复灰显模块。
普通人工注释保持原有行为，不会自动成为停用模块。

保存时通过原始源码范围更新封装，恢复时解包原文，再应用必要的模型差异，保留未知字段、内部注释、查表和换行。
整通道与内部模块可以嵌套停用。专用注释的内容参与保存比对，普通文档注释仍单独展示差异。
从仿真机打开模型时，会尽可能读取已注释引用的外部文件以展示原参数；这类可选文件缺失不会阻止打开其余模型。

## 验证

`node --experimental-websocket tests/module-comments-ui.mjs` 使用真实 Rust XML 解析／生成器和无头 Chromium，验证右键菜单、灰显连线、通道恢复、重新打开、精确源码恢复、共享文件隔离、下游依赖和实时调参隔离。测试不连接仿真机或飞控。
