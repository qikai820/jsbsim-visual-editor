# 本机遥测记录

入口：Tools（工具）→ 遥测记录。

点击“开始记录”，默认创建 文档/JSBSim/Telemetry/telemetry-<时间戳>-<进程号>.jsonl。也可填写其他保存目录。每次开始创建新文件，不覆盖旧文件。点击“停止并保存”会写完队列并同步文件；正常退出应用也会结束记录。关闭记录面板不会停止记录，Tools 图标在记录期间显示红色标记。

记录接收端接受的每条 JSON 对象报文，包含网络和 USB 经本地 UDP 转发的数据。不会按界面刷新频率重复采样，不改变原始字段或单位。记录只能覆盖上位机实际收到的数据：发送端降频、传输丢包、无效 JSON、接收前丢包均无法由文件恢复，也不计入本机队列丢弃数。

文件每行一个 JSON 对象：

- `header`：格式版本、开始时间。
- `telemetry`：`sequence`（本次记录的接收序号）、`received_unix_us`（Unix 微秒时间）、`elapsed_us`（本次记录开始后的单调时钟微秒数）、`peer`（UDP 来源地址，USB 转发为 loopback）、`payload`（收到的原始 JSON 内容）。
- `summary`：结束时间、写入条数和队列丢弃条数。

写盘在独立线程进行，队列最多容纳 4096 条，满时丢弃新报文并计数，不等待磁盘。写入失败会停止记录并报告错误；此前文件保留。每秒刷新缓冲区，正常停止时同步磁盘；异常断电或强制结束可能丢失尾部内容，缺少 summary 代表记录未正常结束。文件中的 written 为遥测条数，不包含 header 和 summary。

记录开始时无需连接仿真机；断线期间保持等待，重连后继续写入同一文件。此功能无需修改或更新板端固件。
