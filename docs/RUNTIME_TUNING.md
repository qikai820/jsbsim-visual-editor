# 运行时调参

编辑器底部的“实时调参”默认开启。连接支持 `VPAR` 的新运行端后，运行或暂停模型时，可以修改下列已有参数：

- `pure_gain`、`scheduled_gain`、`aerosurface_scale` 的数值 `gain`；PID 的数值 `kp`、`ki`、`kd`。
- 已存在的 `clipto` 数值上下限。上下限成组发送，整个事务通过范围检查后应用。
- 常量块，以及 FCS / 气动函数表达式里的 `<value>` 数值，包括原来可在加载时折叠的常量表达式。
- 标准大气海平面压力、温度偏差、湿度、北/东/地向风、湍流类型、20 ft 风速和湍流强度。

输入框在 Enter 或失焦时提交，编辑过程中的空串、负号或指数前缀不会发送。底部提示只有在运行端完成应用并返回实际值、编辑器核对一致后才显示“已应用”。错误或通信超时会保留本地修改，不会自动重启模型。

示波器为可拖动、可从右下角调整大小的浮窗，打开时仍可操作参数面板。

更新由拥有 FDM 的线程在仿真步之间执行，不调用 LoadModel、RunIC、Reset 或重新创建实例。暂停时也能应用，仿真时间保持暂停。示波器继续使用原来的实例、运行代次和历史记录。

## 保存

实时应用不会自动写 SD 卡。在工具栏选择“保存到仿真机”后，增益、限幅和常量进入原有 XML 比对、上传、回读流程。环境卡的数值合并到 `config/models/<model>.json` 的 `environment` 字段，与 XML 一起比对、保存、回读，其他配置分组保持原值。重新从任务机加载模型时会恢复环境卡。也可在“仿真配置 → 环境模型”修改和保存环境参数。

只保存工程会保存本机工程里的参数；要让任务机独立的下次启动使用新值，应完成“保存到仿真机”。

## 边界

仅能实时修改已经加载的数值参数。增删模块、改连线、改表达式结构、把数字改为属性引用、增加新的 clipto、修改查表结构仍需保存并重新加载。编辑器将当前结构与运行会话开始时的结构比较；结构改变后的常量不会套用到旧表达式的另一个位置。

每次事务最多 12 项，最多 32 个实例，实例、模型和运行会话必须匹配。旧运行端没有能力标识时只保留修改，不会把发送成功误报为应用成功。

环境参数接受范围：海平面压力 `(0, 10000] PSF`，温度偏差 `[-150, 150] R`，相对湿度 `[0, 100]%`，三轴风 `[-1000, 1000] ft/s`，湍流类型整数 `0–4`，20 ft 风速 `[0,1000] ft/s`，湍流强度整数 `0–7`。运行端返回设定器实际接受的值；值被运行端截断时提示回读不一致。

## 验证入口

- `node tests/runtime-parameters.mjs`：参数标识、数值差异、限幅成组、环境单位换算、结构变化隔离。
- `cargo test --manifest-path src-tauri/Cargo.toml --test runtime_tuning --test signal_monitor`：协议校验、真实应用 ACK、实际值不符、实例和模型检查、示波器队列。
- `node --experimental-websocket tests/runtime-tuning-ui.mjs <vite-url>`：浏览器中的草稿/提交、应用反馈、关闭调参、失败保留、模型检查和示波器历史连续性。IPC 为隔离模拟，不连接硬件。
- 运行端的 `Tools/test_runtime_tuning.cpp`、`Tools/test_runtime_tuning_udp.py`：真实 JSBSim 和 UDP，检查增益、限幅、常量、环境、状态保持、暂停、重试、会话隔离和保存后的新实例。
