# 本机串口与网口助手

在 **工具 → 串口与网口助手（本机）** 打开。“调试方式”提供串口、TCP 客户端、TCP 服务端、UDP，使用运行 Visual Editor 的电脑上的串口或网络接口。连接参数放在左侧工作台，收发数据和发送区位于右侧；切换到“帧分析”后显示协议分析面板。连接参数单独保存在本机，与仿真机连接和模型配置独立。

## 网口调试

| 调试方式 | 配置 | 行为 |
| --- | --- | --- |
| TCP 客户端 | 目标 IP／主机名、目标端口 | 点击“连接”连接服务端，双向收发字节流；对端关闭后需手动重新连接。 |
| TCP 服务端 | 本地 IP、本地端口 | 点击“启动”开始监听，一次调试一个客户端。状态栏显示实际本地地址及对端地址，客户端断开后继续等待连接；点击“停止”释放监听端口。 |
| UDP | 本地 IP、本地端口；可选目标地址与目标端口 | 点击“启动”绑定端口，每次发送一个报文。设置目标地址后始终发往该目标；目标地址留空则回复最近收到报文的来源，收到首个报文前不能发送。 |

本地 IP 可填 `0.0.0.0`（所有 IPv4 接口）、`127.0.0.1`（本机回环）或指定网卡地址，也支持 IPv6。目标地址可填 IP 或主机名。目标端口范围为 1～65535，本地端口可填 0 让系统分配，实际端口显示在状态栏。UDP 本地地址与目标地址须使用相同 IP 版本，单个发送报文最多 65507 字节。

网口模式复用 HEX／文本、换行、定时发送、帧分析、记录和导出功能；DTR／RTS 只在串口模式显示。原始数据列表显示每批数据的对端地址，帧详情和 CSV／JSON 导出也保留对端信息。UDP 每个报文独立拆帧，TCP 不同客户端连接之间不会拼帧；记录回放保留这些边界。启动后锁定连接设置，停止后可切换调试方式。

## 使用

1. “本机串口”是可输入的下拉框：点击箭头选择检测到的串口，也可在同一框中直接输入设备路径；标题显示检测到的端口数。输入时可筛选串口，支持方向键选择、回车确认和 Esc 收起。波特率可直接选择 9600、57600、115200、230400、460800、921600 等常用值，预设范围为 300～4000000；波特率与串口一样使用可输入下拉框，可在同一框内选择常用值或直接输入该范围内的整数。输入无效时会显示提示并禁止连接，实际支持情况取决于串口设备和驱动。设置数据位、校验位、停止位和流控后点击“连接”。默认参数为 115200、8N1、无流控，设置会保存在本机。
2. 在“原始数据”查看 RX/TX 的 HEX、ASCII 和接收时间。一次读取可能只是半帧，也可能包含多帧，因此这里的行不是协议帧。
3. 在“帧分析”选择固定长度、帧头加长度字段、帧头加帧尾、结束符或空闲间隔。可以设置 SUM8、XOR8、CRC16 Modbus 校验，以及字段偏移、类型、字节序和比例。规则可命名后保存在本机。
4. 发送区支持 HEX／文本、文本换行、历史和常用报文、定时发送；Enter 发送，Shift + Enter 输入换行。左侧“DTR / RTS”可展开设置控制线，只有用户操作后才改变；打开串口时保持库和系统的当前状态。
5. 点击“开始记录”选择本机 `.serialcap` 文件。停止记录后可用“打开记录”离线查看；修改规则后点击“按当前规则重新分析记录”。“导出当前窗口”导出显示缓存中的二进制字节或帧列表 CSV／JSON。

记录文件采用 UTF-8 JSON Lines：第一行是 `format=serial-assistant-capture`、`version=1`，串口模式保存 `port` 参数，网口模式保存 `network` 参数和实际 `localAddr`；之后每行含 `timeMs`、`elapsedUs`、`direction`、`hex`。网口记录另含 `peer`，TCP 含 `streamId`，UDP 含 `datagram=true`。旧版串口记录可继续回放。HEX 保留完整原始字节，方向和时间也可复盘。BIN 导出只保留字节；需要时间、方向或报文边界时保留 `.serialcap` 文件。

窗口为控制内存只保留最近 2 MiB／4000 个接收批次及 4000 帧，超过后明确显示已移出的字节数。已开启的记录文件继续保存原始数据。时间戳取自电脑收到或发出一批字节时，不能代替逻辑分析仪的逐位时序。

Linux 上端口无法打开时，先检查设备权限及是否被其他串口程序占用。串口列表会补充 `/dev` 中存在的 `ttyACM*`、`ttyUSB*` 字符设备；这些补充项可能缺少 USB 设备描述。也可直接输入 `/dev/ttyACM0`、`/dev/ttyUSB0` 等路径。断开或关闭窗口会释放串口，默认不自动重连。

串口底层使用 [serialport-rs](https://github.com/serialport/serialport-rs)，许可证为 [MPL 2.0](https://github.com/serialport/serialport-rs/blob/main/LICENSE.txt)。本项目禁用了它默认的 `libudev` 功能，以保持当前桌面构建环境可用；这不会影响手动输入端口路径。
