# 本机串口助手

在 **工具 → 串口助手（本机）** 打开。它只访问运行 Visual Editor 的电脑上的串口，与仿真机连接、模型文件和 NuttX NSH 控制台没有关系。

## 使用

1. 从“本机串口”下拉列表选择电脑串口；标题会显示检测到的端口数，也可在“设备路径”手动输入。设置波特率、数据位、校验位、停止位和流控，再点击“连接”。默认参数为 115200、8N1、无流控。
2. 在“原始数据”查看 RX/TX 的 HEX、ASCII 和接收时间。一次读取可能只是半帧，也可能包含多帧，因此这里的行不是协议帧。
3. 在“帧分析”选择固定长度、帧头加长度字段、帧头加帧尾、结束符或空闲间隔。可以设置 SUM8、XOR8、CRC16 Modbus 校验，以及字段偏移、类型、字节序和比例。规则可命名后保存在本机。
4. 发送区支持 HEX／文本、文本换行、历史和常用报文、定时发送。DTR/RTS 只有用户操作后才改变；打开串口时保持库和系统的当前状态。
5. 点击“开始记录”选择本机 `.serialcap` 文件。停止记录后可用“打开记录”离线查看；修改规则后点击“按当前规则重新分析记录”。“导出当前窗口”导出显示缓存中的二进制字节或帧列表 CSV／JSON。

记录文件采用 UTF-8 JSON Lines：第一行是 `format=serial-assistant-capture`、`version=1` 和串口参数；之后每行含 `timeMs`、`elapsedUs`、`direction`、`hex`。HEX 保留完整原始字节，方向和时间也可复盘。BIN 导出只保留字节；需要时间与方向时保留 `.serialcap` 文件。

窗口为控制内存只保留最近 2 MiB／4000 个接收批次及 4000 帧，超过后明确显示已移出的字节数。已开启的记录文件继续保存原始数据。时间戳取自电脑收到或发出一批字节时，不能代替逻辑分析仪的逐位时序。

Linux 上端口无法打开时，先检查设备权限及是否被其他串口程序占用。串口列表会补充 `/dev` 中存在的 `ttyACM*`、`ttyUSB*` 字符设备；这些补充项可能缺少 USB 设备描述。也可直接输入 `/dev/ttyACM0`、`/dev/ttyUSB0` 等路径。断开或关闭窗口会释放串口，默认不自动重连。

串口底层使用 [serialport-rs](https://github.com/serialport/serialport-rs)，许可证为 [MPL 2.0](https://github.com/serialport/serialport-rs/blob/main/LICENSE.txt)。本项目禁用了它默认的 `libudev` 功能，以保持当前桌面构建环境可用；这不会影响手动输入端口路径。
