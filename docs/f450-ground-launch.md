# F450 USB 模型启动跌落

`jsbsim_f450_us_1794223982.mcap` 记录了 59.76 秒仿真。四路电机的指令和
执行值全程为零，初始机体海拔约 582.77 米，但初始离地高度同样约 582.77 米，
物理地面海拔为零。模型先自由落体，随后触地弹跳并出现很大的角速度。
录制正常由停止命令结束，日志没有记录队列或 RAM 丢包。

板端 `aircraft/f450_usb/initGrnd.xml` 已有正确的地面初始化：机体海拔
582.77 米，地面海拔 582.57 米。对应 `scripts/f450_usb.xml` 通过
`<use aircraft="f450_usb" initialize="initGrnd"/>` 读取这些条件。
直接加载 aircraft XML 不会读取这个初始化文件，因而仍使用默认的零海拔地面。

## 启动修复

外部仿真机的正常模型启动现在检查同名 `scripts/<model>.xml`。只有脚本为
该模型的简单地面初始化、从零时刻开始且只配置运行时间/步长时，才自动沿用
该脚本。带事件、控制命令、其他初始条件或其他模型的场景脚本仍需明确选择。
用户明确选择的脚本优先，没有同名脚本的模型继续沿用直接加载方式。

这样 `f450_usb` 的“开始”发送 `LOAD_SCRIPT`，板端先读取 `initGrnd`，再应用
已有运行配置。无需修改地理位置、执行器映射、飞控参数或固件。

## 验证

- 使用板端实际物理模型文件进行桌面对照：直接加载模型，16 秒后海拔降到
  78.09 米；加载地面脚本后连续 60 秒稳定在约 582.7235 米。
- `cargo test --manifest-path src-tauri/Cargo.toml --test model_launch` 验证
  普通模型启动、显式脚本优先、场景脚本排除及 XML 错误路径。
- `cargo check --manifest-path src-tauri/Cargo.toml` 检查完整编辑器后端。
- 实际点击编辑器“开始”，抓包确认发送 `LOAD_SCRIPT f450_usb.xml|f450_usb`。
  新日志 `jsbsim_f450_us_1794224533.mcap` 完整记录 107.16 秒、5358 个 FDM
  样本，最大采样间隔 0.02 秒。2 秒后海拔保持 582.72351 米，垂直速度绝对值
  小于 `1e-7 m/s`，四路电机指令始终为零。停止后日志正常收尾，Footer、Chunk
  CRC 校验通过，队列/RAM 丢包均为零；板端 HIL 发送错误和丢弃均为零。

上述地面验证不涉及解锁或闭环飞行。
